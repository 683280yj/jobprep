## 第 0 步：官网注册与实名（提前 3 天）

1. 打开 [中国版权保护中心](https://www.ccopyright.com.cn/)，注册账号并完成实名认证
（实名审核约需 3 天，建议现在就去注册，材料都已备好、等人不等证）。
2. 本次申请按**个人**申报：选「我是申请人」，著作权人为你本人。
（学校/单位评优若要求著作权人为学校，流程会复杂很多，需要学校盖章；
如无硬性要求，个人申报最省事。）

## 第 1 步：在线填报（约 30 分钟）

1. 登录后进入业务办理 → **R11 计算机软件著作权登记** → 我是申请人。
2. 软件全称：`求职备考管理软件`；版本号：`V1.0`；软件分类：`应用软件`；
开发完成日期：`2026-10-06`；发表状态：**未发表**（选未发表少填很多）。
3. 著作权人信息按你的身份证如实填写（姓名、身份证号、地址、手机号）。
4. 十几项技术填空：直接复制 `docs/填报字段内容.txt` 中的对应文案粘贴，
字符数已按官网限制（50 字符 / 500~1300 字符 / 100 字符）逐项校验过。
5. 上传鉴别材料：交存方式选「一般交存」，上传上述两个 PDF。
其他证明材料没有可跳过。

## 第 2 步：验证码与提交

1. 确认信息无误后提交，手机会收到的授权验证码，
**1 小时内有效，不要关闭浏览器窗口或断网**。
2. 在线填报完成。

## 第 3 步：打印承诺页并签字上传

1. 在申请页面下载申请表/承诺页，只需填写右下角：**手写签名 + 身份证号**。
2. 注意：承诺页版本偶有变化（是否含"未使用 AI"承诺、手抄内容），
以你下载到的那份为准，按上面的字样如实填写。
3. 签好字后拍照/扫描上传，提交。整个申请流程结束。

## 第 4 步：等待

- 定期登录官网查看进度，正常 1~2 个月下证（评论区多位 2 个月内下证）。
- 若收到补正通知：按要求改对应材料即可，常见原因是格式问题；
本材料包已按"页眉软件全称+版本号、60 页、每页 61~62 行、无封面、
尾页闭合、截图真实且与申请表一致"逐项自查，可最大程度避免补正。
- 若被问及原创性：本软件为全新开发，源码、提交记录都在你手里，
可提供 git 记录自证（建议把源码 push 到你 GitHub 私有/公开仓库留存证据链）。
